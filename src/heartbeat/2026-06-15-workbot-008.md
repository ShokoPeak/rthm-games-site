The big structural thread closed — the live trading simulation is now rendering on the Blender-built NPSE chart wall with a real player walking around. First time the gameplay and the modelled world have shared the same scene.

- **Screen substrate shipped** — three new scripts wire 2D Control UIs onto 3D surfaces via SubViewport:
  - `World/ScreenContent.gd` — generic binder; handles the `-col` import wrapper, UV-rect cropping (defends against atlas-style unwraps and partial V ranges), and tile-along-axis detection for repeated-UV surfaces
  - `World/NPSEChartWall.gd` — finds and wires the 6 chart-wall monitors (MainChart, Ticker, Chart 5m/15m/1h/4h) plus the DayClock
  - `World/TCBoothScreens.gd` — wires the 5 TC booth instances; each booth's edge ticker emissive matches its plastic counter colour (Magenta / Tan / Green / Red / Cyan)
- **Live sim wired into the Blender world (MC-1..MC-4)** — a new `World/BlenderFloor.tscn` instances `CityBackdrop` + `GameManager` + a real Player + `CameraFocusTarget` + the chart-wall binders. `TradingFloor.tscn` stays untouched as the fallback.
- **`GameManager.chart_wall_path`** — new `@export`; when set, GameManager defer-resolves `_chart` / `_monitor_vp` / `_ticker` / `_mini_screens` from the NPSEChartWall accessors instead of the old hardcoded TradingFloor sibling paths. ~10-line guarded change.
- **`World/MiniScreens.gd` refactor** — now accepts injected charts/viewports via `configure_injected(gm, charts, viewports)` so the same component works in TradingFloor (scene-built) and BlenderFloor (binder-injected) without logic duplication.
- **`UI/NewsTicker.gd`** — draw math now reads live control size, fixes the ticker not spanning the wider NPSE ticker surface. Old TradingFloor ticker (1440×130) unchanged.
- **`UI/DayStartPrompt.gd`** — new on-screen "[E] OPEN MARKET / START DAY N" CanvasLayer. Replaces the physical OrderTaker booth in the Blender scene; gating mirrors `OrderTaker._can_interact()`.
- **Verified live** — main wall candles drawing, four minis at correct timeframes, ticker present, console confirms `Chart wall bound: chart=true ticker=true minis=true vp=true`.

**Design direction this cycle:**

- **Jackpot cluster reconceived as a Market Relief Fund** — UK Premium Bonds-style. Players invest into a shared pot; capital is parked, each draw has a small chance of payout scaled by how much you've invested. Doubles as the bust-second-life mechanic. Replaces the scratch/slots framing for that cluster.
- **Trader Tablet (Tab key)** — handheld UI surfacing live prices, ticker, positions, P&L. Same SubViewport pipeline as the chart wall. Skinnable with real-brokerage aesthetics (Robinhood-pink, Webull-dark, Bloomberg-orange-on-black...) as unlock cosmetics — tablet only, world surfaces stay native.
- **Modding plan** — `user://mods/`, asset+data only, no code execution. Skipping Steam Workshop entirely; moderation burden too high for solo dev.
- **EOD calls** and **seasonal world decoration** captured as future hooks.
