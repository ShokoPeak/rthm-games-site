Two back-to-back big sessions. Multiplayer is finally alive again and the first playable LAN demo build shipped out of the door.

**LAN demo build**

- **`Export/MarginCall-LAN.zip` shipped** via the Windows export preset + build pipeline.
- **`/Export/` gitignored**, Syncthing set up to push the folder over to the laptop for two-machine testing.
- **`World/RunLogger.gd`** — anonymous perf logger that drops hardware + FPS data next to the `.exe` so testers can send their runs back for triage.
- **Steam appid registered** (`4594490`); dev-account gotchas captured (personal login fails `ConnectToGlobalUser`; achievements need Steamworks backend definitions; `steam_appid.txt` gets stripped on ship).
- **Hard rule banked:** always validate against the real exported `.exe` — editor and headless test harness both hide export-only bugs. Caught during this cycle: `ItemDatabase` was loading a `.tres.remap` under export → 0 items visible in-game. Fixed. Editor GUI console wrapper is editor-only, so the ship build gets the plain console.

**Multiplayer reinstated**

The MP layer went from broken to compiled-into-the-demo. Two root-cause classes fixed:

- **Scene-name hardcoding** — several MP paths were still looking up nodes by the old TradingFloor scene name, so anything running in BlenderFloor silently dropped its sync. Rewired to scene-agnostic lookups.
- **Account-sync gaps** — a handful of account fields never made it into the sync payload, so client state drifted after any bust / commission / EOD payout.
- **Commission-payout indentation fix** — a stray indent meant commission wasn't paying on winning closes for clients (payload arrived, branch never ran).
- **5× starter network parity** — the new starter item now hydrates correctly on join.
- **Client sun-smoothing** — the day/night sweep now interpolates client-side so clients don't jump between host tick positions.
- **Live 2-client smoke test is the only remaining gate** — headless can't verify UX, so this is the last piece before the LAN session.

**Bug squash pass**

- Commission now pays on winning closes (see above)
