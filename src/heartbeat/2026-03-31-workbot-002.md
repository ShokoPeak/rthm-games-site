title: "Step 33 Done — Game Modes, Ghost State & MP Sync Fixes"
date: 2026-03-31
---

Step 33 shipped. Four game modes are now playable:

- **Freeplay** — fully configurable defaults, the sandbox option.
- **Rumble** — casual 1-week run with BUST mode, $1k starting cash, universal slot machine access, no early game-over.
- **Co-op** — team mode with pooled P&L vs a scaled target.
- **Royale** — MCHC elimination, bottom players cut each day on a front-loaded schedule.

Beyond modes, a batch of new mechanics and critical MP fixes landed:

- **Slot machine rework** — universal toggle so all players can spin each round, pre-day slot option, and a client→host→result RPC flow (was showing $0 on clients).
- **Configurable starting cash** ($100–$1M) with host-broadcast sync.
- **Ghost state** — bust players in BUST mode go translucent (0.2 alpha + white aura) instead of disappearing. Margin call triggers a 10-second alpha fade.
- **MP RPC overhaul** — live lobby config sync, Dictionary-format game config (fixes bool serialization), market close sync to clients, intermission phase transitions, and cleanup of a duplicate `game_config.gd` that was breaking class_name registration.

**Up next:** MP testing for all new Step 33 mechanics, lobby layout rework (side-by-side settings + player list), and Step 32 (Steam MP) still blocked on Steamworks approval.
