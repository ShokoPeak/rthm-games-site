title: "Blender → Godot Pipeline Milestone Shipped"
date: 2026-05-05
---

A meaty pipeline sprint just landed — the Blender→Godot asset pipeline is fully end-to-end working and pushed (commit `7a5e61c`).

- **10 archetypes instanced via manifest** — 6 buildings + pavement + 3 props, with 125 placements driven by `assets/manifests/placement.json`. Source-of-truth is the manifest; the importer fans out from there.
- **8 composites instanced at world origin** — driven from `assets/environments/`. Composites sit alongside archetypes without namespace collisions.
- **`World/WorldImporter.gd` EditorScript** — bakes the assembled scene to `World/CityBackdrop.tscn`. Idempotent; permanent `ResourceLoader.CACHE_MODE_IGNORE` so re-bakes always pull fresh from disk.
- **Coord conversion verified** — Blender Z-up → Godot Y-up, including composite positioning. Self-check now runs on the Blender side to catch future regressions before export.
- **7-layer collision scheme live** in `project.godot`. Collision properties bulk-applied across 38 `-col*` shapes, 6 architectural surfaces, and 3 composite props — set on the Blender side so the import pipeline preserves them automatically.
- **Ownership scoped to structural nodes only** — no namespace flattening, scene tree stays readable.
- **Three real bug-and-fix cycles survived during this sprint:**
  1. Composite scope leakage (archetypes bleeding into composites) — fixed Blender-side.
  2. Resource cache + ownership recursion — fixed Godot-side.
  3. Composite positioning bbox-recentering bug — fixed Blender-side.

**Next priority — Phase 1: parent `World.tscn`** wrapping `CityBackdrop.tscn` with `WorldEnvironment` (sky/fog/tonemap), `DirectionalLight3D` (sun matched to day/night), `OccluderInstance3D` bake, player spawn point in NPSE, and the existing `DayNightLighting.gd` adapted in. Target is a "press play and walk around" milestone.

**Then Phase 2 — toon shader + material substitution.** `toon_shader.gdshader` in Godot (cel + edge detection), then a post-bake pass that walks the scene, matches `Mat_*` materials by name, and substitutes the toon-shaded equivalent. 46 materials all named `Mat_*` so name is the join key — placeholder PBR values get fully replaced.

**Lower priority queue:** trading post decagonal template (bundle with the 4 trade-pit pod refactor, currently ~66k verts each), low-poly remodels for `prop_ac_unit.glb` and `small_back_bld.glb`, and casino wing scene wiring (Steps 36c–36f panels/booths still need placement in `TradingFloor.tscn`). Step 33 bugs still open on the queue.
