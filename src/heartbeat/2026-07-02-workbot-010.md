---
title: "Diegetic Menu, Trade Cluster Screens, Tablet Browser & TC Money Overhaul"
date: 2026-07-02
---

Substantial cycle. The whole path from boot to gameplay is now diegetic, the trade cluster screens are live, all booth UIs migrated to a tablet browser, and the forecasting minigames now stake real cash on a proper commission model.

**Boot → game flow (main menu is now in-world)**

- **`World/MenuWorld.tscn`** — new boot scene. Billboard menu is drawn on the NPSE tower's `Mat_Screen` (red-on-black) with mouse + keyboard nav and translucent config panels.
- **Launch cinematic** — marker-driven tween `MenuCamera → MenuCameraTD → hold → MenuCameraTarget`, then fade-to-black → `World/BlenderFloor.tscn` fades back in via `UI/FadeOverlay.gd`. `GameConfig.current` carries settings across the transition.
- **BlenderFloor promoted to normal-loop gameplay scene** — GM / ShopPanel / NPC lookups now scene-agnostic via `get_tree().current_scene` so the same code runs from either boot path.
- **Countdown / day-start polish** — EOD board clears on `countdown_started`; final beat now reads "MARKET OPEN!"; sun day/night sweep is relative to its authored pose (no snap) and does a **gated sunrise** during the count-in (rises + brightens, skips day 1 when the sun is already up, gated on `_is_night`).

**Trade Cluster screens — DONE (2026-06-29)**

Full ring of TC in-world content is live and themed per booth:
- `World/BoothScreenContent.gd` — new: renders the branded board + the ring of live-data screens + rotating sponsor adverts per cluster
- `World/TCBoothScreens.gd` — wired to `BoothScreenContent` per booth (Prediction / Binary / Crypto / Scratch / EoD)
- `World/MonitorScreens.gd` — booth exclusion so desk-monitor set-dressing doesn't clobber TC surfaces
- `Config/TickerFlavour.gd` — sponsor rotation feed
- Board/drum material split re-baked on the Blender side so each cluster carries its own art
- Styling pass still owed — folded into the MC-12 cohesive pass

**Booth / terminal UI → Trader Tablet "browser" — DONE (2026-06-30)**

All 9 station UIs (5 booths + ATM/Shop; Slot and Donation intentionally kept native) now open as themed browser pages on the Trader Tablet instead of dimmed pop-ups.
- Booth panels converted to editable `.tscn` (ATM / EOD / Scratch / Binary / Shop / RugPull / Prediction) with a shared Help toggle
- Prediction + EoD get `@tool` dummy-data editor previews
- Per-service page backgrounds via `Tablet.gd` PAGE_THEMES (each service has a distinct hue)
- Prediction tiles reworked into a Kalshi-style two-row layout (YES + NO as separate rows, bar + pill + multiple); confirmation view collapses the trade UI + tall readouts to fit
- `[E]` interaction-prompt z-fight fixed

**TC money overhaul — DONE (2026-07-01/02)**

The forecasting minigames were built on placeholder economics. Now they run on the real money model:
- **Forecasting TCs (Prediction / Binary / Crypto / EoD)** now stake real `account.cash`; standard bust rules apply
- **Commission model** — market-maker income shape: per-close profit-weighted log-capped skim + a ramped daily-survival credit
- **Crypto sparkline** — 10-bar cashout chart drawn into the panel
- **EoD Calls built from scratch** — 17-bucket price-ladder: keystone open band in the centre + two columns of tail buckets, 15× / 10× payout tiers, ±30% range
- **RunTests 88 / 94** — the 6 fails are pre-existing leverage-P&L tests carried over from before this cycle; not regressions

**Small fixes**

- `UI/DonationDisplay.gd` font sizes and offsets bumped ~2.2× for readability
- `World/DonationBox.gd` `INTERACT_RADIUS` 1.5 → 3.0 m to match the TC booths' reach

**Ticker plumbing polish**

- Feed now seed-shuffled at run start, plays 7 headlines/day on a loop, advances to the next slice each day, reshuffles + rerolls per cycle. Marquee speed dropped to 60% of prior for legibility.
- Auto-tagged company chips: flavour lines that mention a canon entity get an inline coloured "±X%" chip rolled per-instance per-cycle and held for the day.

**Next:** the multiplayer layer is still untested end-to-end — sync broken, NPCs not moving, players invisible to each other. That's the next session. After that: banking/shop kiosk geometry (still plain grey mesh boxes with no screen faces), the MC-12 cohesive style pass, and the toon shader + material substitution pass.
